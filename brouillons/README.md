# Mes brouillons

Ce dossier existe uniquement sur la branche `brouillons`. Il n’est pas déployé sur le site. Le dépôt est public : ce dossier reste visible sur GitHub.

Copier le contenu de modele.html dans un nouveau fichier, par exemple mon-test.html, puis l’éditer avec le crayon GitHub. Garder le statut draft pendant la rédaction et enregistrer sur la branche brouillons.

Pour publier : passer le statut à ready, lancer « Préparer la publication d'un article GitHub » depuis Actions avec la branche main et le nom mon-test, puis relire et fusionner la pull request produite.

Ne jamais fusionner toute la branche brouillons dans main. Le modèle ne peut pas être publié.

[Procédure complète](https://github.com/dingodorone/dingodor-one-tech/blob/main/README.md)
