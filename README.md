# Dingodor One Tech

Site statique officiel de Dingodor One Tech, publié sur GitHub Pages avec le domaine `dingodoronetech.eu.org`.

Les nouveaux articles doivent être rédigés dans un espace privé avant publication. Le dépôt principal est public et ne doit jamais contenir de brouillon, d’exclusivité ou de contenu sous embargo. L’ancien WordPress reste conservé pour les archives et les contenus existants ; les nouveaux articles validés sont publiés uniquement sur le nouveau site.

La première interface de rédaction publique a été désactivée parce qu’elle exposait les brouillons sur GitHub. Le prochain éditeur devra utiliser un dépôt privé ou un stockage privé authentifié, puis transmettre uniquement l’article validé au workflow de publication. Ne réactivez pas une rédaction dans ce dépôt public.

## Publications programmées WordPress

Le workflow « Pages et sitemap des articles » récupère les articles déjà publiés sur l’ancien WordPress. Il crée et déploie leurs pages, vérifie le contenu réellement accessible, puis met à jour les listes, le sitemap et les notifications. Un nouvel article rédigé dans un espace privé devra suivre ce même contrôle avant d’être ajouté au site.

Les anciennes pages et leurs URL sont conservées. Les index validés alimentent le site et l’application ; les notifications revérifient la page avant chaque envoi.
